## ListyCity

A simple Jetpack Compose app for adding and editing cities and provinces.
The layout follows the lab example: a two-column list with dividers and a
floating **+** button in the upper-right corner.

### Run the app

Open the `code` folder in Android Studio, sync Gradle, and run the `app` target
on an emulator or Android device (API 24 or newer).

### Use the app

- Tap **+**, enter a city and province, then tap **Add City**.
- Tap an existing row to load its values, change either field, then tap
  **Update City**. The selected row is replaced in place.
- Tap **Cancel** to discard changes. Both fields must contain nonblank text
  before saving; leading and trailing spaces are removed.

Cities are held in memory for the current activity, as permitted by the lab;
restarting the app or recreating the activity restores the starter list.
